# Code of Conduct

This project welcomes practical, respectful collaboration.

## Expected Behavior

- Be direct about technical risks and trade-offs.
- Assume good intent, but keep discussions evidence-based.
- Keep feedback focused on code, behavior, tests, documentation, and user impact.
- Respect maintainers' time by providing reproduction steps and clear context.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Publishing private keys, customer certificates, passwords, tokens, or private data.
- Repeated off-topic comments after maintainers ask to stop.
- Pressure to merge risky changes without tests or review.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues; block participants; or reject contributions that violate these rules.
